The challenge

Feedback on software arrives as "that button looks wrong". A screen recording helps a person, but an AI coding agent cannot watch a video and know which button was meant. People needed to give feedback by talking and pointing, and agents still needed to read it precisely.

How I solved it

  1. 1

    Transcribe on the device.

    Open-source Whisper models run locally, so there is no API key, no cost and no upload of client screens.

  2. 2

    Tie each spoken phrase to the mark drawn at that moment.

    The box or arrow drawn while talking tells the agent what "this" means. Marks cleared during the recording drop out of the screenshots and video.

  3. 3

    Write one bundle that people and agents can both read.

    Each capture produces a review page, Markdown and JSON notes, screenshots and a video with the marks burned in.

  4. 4

    Let agents start a capture, but only with consent.

    An MCP server and a Claude Code plugin can start and stop a recording behind a consent gate. A setup check refuses to record on a dead microphone.

Outcome

  • Seven tagged releases for Windows and Linux, v0.1.0 to v0.5.1, with auto-update.
  • The idea outlived the app: Anvil later rebuilt recording natively, reusing the design, not the code.

Record any app and draw over it while you talk: boxes, arrows and text pins.
